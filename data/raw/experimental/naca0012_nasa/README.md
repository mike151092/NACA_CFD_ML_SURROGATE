# NACA 0012 NASA Experimental Data

## Source

NASA Langley Research Center

## Experiment

Low-Speed Aerodynamic Characteristics of the NACA 0012 Airfoil Section

## Purpose

Experimental reference data for validation of the OpenFOAM CFD model.

## Variables

- Angle of attack
- Reynolds number
- Mach number
- Lift coefficient
- Drag coefficient

## Status

Dataset identification phase.
